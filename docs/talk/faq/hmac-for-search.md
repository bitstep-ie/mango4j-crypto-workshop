Why do I need to HMAC data to make it searchable?

With the usual randomized or nonce-based encryption schemes, the same plaintext produces different ciphertext each time (see [What's an IV, and why does it matter?](iv.md)), so ciphertext is not normally suitable for equality search. A HMAC of the same normalized value, computed with the same key, is deterministic; storing it alongside ciphertext enables equality lookup by HMAC. This also reveals equality between matching stored values, so normalization, authorization, and key management are part of the design. See [Introducing HMACs](../introducing-hmacs.md).

What HMAC strategies does mango4j-crypto support?

Three, chosen per entity via a class-level annotation: Single HMAC, Double HMAC, and List HMAC. mango4j-crypto's own authors recommend List HMAC as the default unless there's a strong reason not to use it — see [Single HMAC Strategy](../single-hmac.md) and [List HMAC Strategy](../list-hmac.md) for the trade-offs.
